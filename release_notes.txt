v2.5.1 - Profile Update Fix

Root cause: full_name column does not exist in user_profiles table.
It lives in auth.users metadata. Updates to full_name were silently
ignored by PostgREST.

Fix:
- full_name now updates via Supabase auth.updateUser(data: {full_name})
- Other fields (exam_category, target_year, daily_study_hrs, institution,
  city) update user_profiles table as before
- After update, currentUser is refreshed to reflect new metadata
- Edit dialog shows error message if update fails
