v2.5.0 - Major Bug Fixes & Full Profile Editing

PERFORMANCE (biggest fix):
- Router no longer recreates on every auth state change. Used
  GoRouterRefreshStream pattern instead of ref.watch. This was the
  main cause of app slowness and navigation glitches.

PROFILE EDITING:
- Edit dialog now has ALL fields: Full Name, Exam Category (dropdown),
  Target Year (dropdown), Daily Study Hours (dropdown), Institution, City
- Shows friendly exam names (CA Foundation) not codes (CA_FND)

TESTS:
- Retake button shown for previously attempted tests
- Result screen shows score percentage, correct/wrong/skipped counts
- Retake option on result screen
- submitTest deletes old submission before inserting (allows retakes)

RESOURCES:
- YouTube links now load properly by exam (fetches through chapters)

NAVIGATION:
- Root and shell navigator keys prevent back-button issues
- Bottom nav items have fixed type for proper styling
