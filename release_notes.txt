v3.1.1 - Fix Notifications When App Is Killed

BUG FIX:
- Notifications now fire reliably even when app is closed/killed
- Changed to exact alarms (exactAllowWhileIdle) for guaranteed delivery
- Added USE_EXACT_ALARM permission for Android 14+ compatibility
- Added WAKE_LOCK to prevent CPU sleep before notification delivery
- Notification receivers re-exported so BOOT_COMPLETED works after reboot
- Notifications auto-re-schedule on every app launch
- Added POST_NOTIFICATIONS runtime permission request (Android 13+)
- Added 'Send Test Notification' button for instant verification
